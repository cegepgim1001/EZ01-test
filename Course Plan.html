Course Overview

This section provides the foundational context for the course, including the core philosophy behind our tools and labs.

This course is the first in the Cybersecurity intensive program leading to an Attestation d'études collégiales (A.E.C.).

It provides students with an overview of cybersecurity prevention and response activities, serving as a foundational pillar for the profession. By the end of this course, students will be capable of monitoring a network to detect anomalies, intrusion attempts, and data exfiltration.

Topics include the installation and configuration of network monitoring tools on Windows/Linux servers, router/switch monitoring, and the documentation of network anomalies using both on-premises equipment and cloud platforms like AWS and Azure.

🔧 Open-Source & Custom Tools

The tools provided in this course are intended to serve simply as a "framework." Students are highly encouraged to research and utilize open-source alternatives based on their interests, or even create their own custom tools and use them instead during the labs!

🚀 Integrated Course Project

All hands-on labs are strategically connected. Rather than isolated exercises, they will continuously build upon one another to form one big, comprehensive project that will span during all of the Course!

Competencies & Policies

Explore the core competencies (EZ01) you will master and the academic policies governing your success and integrity in this course.

Competency Statement (EZ01)

To monitor a computer network from a cybersecurity perspective.

1️⃣

Identify Concepts

Recognize CIA issues, differentiate cyberattack types, and distinguish performance vs. security issues.

2️⃣

Analyze Topology

Examine organizational contexts, identify monitoring needs, and prioritize activities.

3️⃣

Configure Tools

Select tools, configure baselines, and set up alerts on systems.

4️⃣

Detect Anomalies

Use tools to analyze network traffic, event logs, and files to detect and properly document incidents.

5️⃣

Optimize Tools

Update baselines, reduce false positives/performance impact, and recommend new capabilities.
